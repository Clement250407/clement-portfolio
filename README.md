# Portfolio de Clément André

Site public statique pour GitHub Pages. Le site ne demande aucun compte pour être consulté.

## Mettre la version à jour sur GitHub Pages

1. Télécharge et décompresse `clement-andre-portfolio.zip`.
2. Ouvre ton dépôt GitHub `Clement250407/clement-portfolio`.
3. Choisis **Add file → Upload files**.
4. Glisse les fichiers décompressés dans le dépôt : `index.html`, `style.css`, `script.js` et le dossier `assets`. Ils doivent être directement à la racine du dépôt, pas dans un dossier `clement-andre-site`.
5. Coche le remplacement des fichiers déjà présents si GitHub le demande.
6. Clique sur **Commit changes** sur `main`.
7. Dans **Settings → Pages**, garde `main` et `/(root)` comme source. Après quelques minutes, le site sera à l’adresse : https://clement250407.github.io/clement-portfolio/

## Formulaire de contact

Le formulaire utilise FormSubmit. Au premier envoi, FormSubmit transmet un e-mail de confirmation à Clément. Il faut ouvrir cet e-mail et confirmer l’adresse avant que les messages du formulaire soient transférés. Ensuite, fais un essai depuis le site publié.

## Fichiers du site

- `index.html` : toutes les sections et le contenu du portfolio.
- `style.css` : mise en page, couleurs et adaptation au téléphone.
- `script.js` : menu de navigation sur téléphone et année du pied de page.
- `assets/cv-clement-andre.pdf` : CV en PDF, à télécharger.
- `assets/cv-clement-andre-apercu.png` : aperçu du CV montré dans la page.
